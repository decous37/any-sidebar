Any Sidebar · 隐私说明

适用版本：0.2.2。更新日期：2026年10月24日。

Any Sidebar是用户自备 DeepSeek API Key 的第三方 Chrome 扩展，与 Google 或 DeepSeek 没有官方关联。

读取和保存什么

侧边栏打开时，扩展按权限读取对应窗口的活动网页主文档中已经加载的文章正文、标题、地址和合规的划选文字。不会主动遍历其他标签页正文，不读取浏览历史或 Cookie，不采集输入框、密码或可编辑区域内容。关闭侧边栏后停止新增采集。

对话、草稿、网页引用、AI 回答引用与来源、旧回答及请求使用的上下文副本保存在本浏览器的 IndexedDB；API Key 与模型、引用模式、主题等偏好保存在受限的本机扩展存储。当前侧栏与网页绑定登记在浏览器运行期间临时保存。本扩展不使用云端同步。

什么时候发送给 DeepSeek

只有主动发送问题（包括点击推荐提问）、手动重试或重新生成时，扩展才直连 https://api.deepseek.com/chat/completions，将本次启用的正文、引用、问题及必要的成功历史消息提交给 DeepSeek。Key 仅用于官方请求认证。仅打开、读取、划选、切换网页或主题不调用模型。

发送后的内容由 DeepSeek 按其服务条款与隐私政策处理。用户自行配置 Key 并承担官方 API 用量费用。本扩展无项目方服务器、账号、遥测、广告或第三方分析服务，不将数据发送到项目方。

本机保护与限制

网页与内容采集脚本不能直接读取 Key 或其他网页会话。Key 不写入对话、上下文副本或日志。本机存储不等于加密保险箱，拥有本机或开发者工具访问权限的人可能访问扩展记录。

网页和回复均作为不可信内容处理，不执行脚本、自动图片或网页动作。普通外链只在用户主动点击时打开，之后按目标网站的规则运行。

权限用途

sidePanel 用于原生侧栏；storage 用于本机记录与设置；scripting 和 activeTab 用于用户操作后读取当前主文档；webNavigation 用于核对当前文档与文章路由。HTTP/HTTPS 网站访问权限在安装时由 Chrome 统一声明，用于打开侧栏与切页后自动读取当前文章，同时允许连接官方 API；实际网络连接受内容安全策略限制为 DeepSeek 官方地址。用户在 Chrome 中限制网站访问后，仍可使用纯文字对话。

清除和控制

可在设置中清空当前网页或全部网页的对话、草稿、引用与关联快照；清空会话保留 Key 和偏好。单独清除 Key 可阻止后续发送，已发出的请求可能继续完成。Chrome 的扩展管理和网站权限设置可撤销网页访问权限。卸载扩展会移除本机扩展数据。

生成时切换网页，回答仍归属原会话；关闭侧栏或窗口将中断该实例的生成，已保存内容保留，不自动重新调用。
