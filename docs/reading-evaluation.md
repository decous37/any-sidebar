# 0.2.2 阅读理解对照评测

这是待执行的回答质量评测，不是“模型效果已改善”的证明。当前仅完成公开样例的上下文构建检查，不调用真实API。样例为项目自编并随源码公开，不归因于真实网站；没有私人文章或Key。

完整文章、选文、追问历史、预期关键点和禁止编造项见 tests/fixtures/reading-cases.ts。运行单元测试会生成 artifacts/verification/reading-evaluation-inputs.json，其中包含0.2.1原提示/原顺序与reading-v1的成对请求消息，未包含回答。

| 样例 | 应观察到的回答 |
|---|---|
| 代码与文章流程关联 | 解释过滤/描述生成，联系注册到执行的分工，不声称此函数执行工具 |
| 必要知识补充 | 联系用户ID索引场景，说明查找与维护代价，区分补充知识 |
| 缺失实现 | 识别validate调用，承认实现未展示，不断言没有校验 |
| 原文错误 | 纠正Python list不可变的错误，并给简短依据 |
| 连续指代 | 将“第二个”理解为描述器，承接前文职责分工 |
| 换方式解释 | 用具体读写例子替换抽象复述，不编造事务实现 |
| 明确要求简短 | 一句话回答，不因默认关联策略强制展开 |
| 正文读取失败 | 说明没有取得全文，不编造缓存更新策略 |

后续经用户授权进行真实评测时，两组固定使用deepseek-flash、开启思考、low；其他请求设置相同，同一组不更换模型或强度，不将示例预期发送给模型。每组记录设置、日期、原始回答与人工结论；输出可能有随机差异，一轮不代表所有模型表现。

每条回答按正确性、关联依据、来源区分、篇幅四项分别记录通过/未通过/不适用，并列出具体证据。编造文章事实、附和可确认错误、无正文却声称读过全文属于关键失败。对比采用逐例结果，不能只看长度或是否提到文章。基线已正确时应保持正确，不能要求优化后一定更长；未实测项保留未验证。
