# Any Sidebar 使用指南

## 开始阅读

点击工具栏中的扩展图标打开原生侧栏。插件自动提取当前网页已加载的文章正文，输入框内的小字显示读取状态和文章标题。发送前会再次读取当前内容。安装时声明 HTTP/HTTPS 网站访问权限，日常阅读无需逐页点击授权或读取。

首次进入设置，填写 DeepSeek 官方 API Key 并保存。只显示是否已配置；替换需要输入新值。Key 仅在本机扩展存储保存，用于向官方 API 认证，用量按你的 DeepSeek 账户计费。

## 提问和引用

输入问题后按 Enter 或点击发送；Shift+Enter 换行。点击推荐项会直接发送，不会只填写输入框。未配置 Key 时先显示提示，确定后定位配置入口，问题与引用保留。

在网页正文中划选文字后，引用自动出现在输入框上方。设置中可切换：

- 累积引用：逐段追加；取消选中仍保留，可逐条删除。
- 仅最新引用：新选文替换旧选文；取消网页选中时，对应的待发送引用自动移除。已发送消息里的引用保留。

输入框、密码和可编辑区域不采集。引用与草稿跟随当前网页保存。发送准备成功后仅清理本次提交的内容；准备期间继续输入的新内容保留。

正文在本机自动读取。读取成功时，发送会包含当前正文；读取失败时显示“未读取正文”，可以直接用问题、引用及必要历史提问，也可以点状态行旁的重试。不会使用其他网页的旧正文。仅打开或划选不调用模型。

AI 回答引用独立于网页引用，最多一条。划选另一段会替换 AI 引用；点击回答区域空白取消选中会移除该引用，进入输入框打字会保留。每条待发送引用以单行显示，点击可以查看全文，显示省略不影响实际提交全文。

## 模型和回答

在输入框下方直接切换 DeepSeek 官方模型，并在思考菜单中选择关闭、低、高或最高。修改影响后续发送或重试，不改变已经发出的请求。

回答逐步显示，思考过程默认折叠。支持代码、表格及复制。点击停止可中断；连接失败、限流或余额不足会显示原因，需由你手动重试，不自动重新计费。上下文过长时会阻止发送，可移除部分引用或清空当前会话后再试，不会静默截断资料。

回答下方可复制、引用整条回答，或点“追问”引用并聚焦输入，保留已有草稿。仅最后一条已完成回答提供“重新生成”：使用原问题及原上下文、当前模型设置再次调用 API，产生用量；成功替换展示，失败或停止恢复原回答。旧记录保留本机，不增加复杂版本管理界面。

缺 Key 时发送会先弹出提示；点“确定”才打开并定位 Key 输入框，问题与引用保留，保存 Key 后不会自动发送。

## 网页会话和本机记录

不同地址使用不同会话，路径和查询参数参与区分，已确认的同篇页内锚点沿用会话。切换网页时原请求可继续，回答归属原会话。关闭侧栏或窗口会中断该实例的请求，已经保存的输出保留。

设置中可以清空当前网页或全部网页记录，确认后删除相关草稿、引用、消息和请求快照，同时保留 Key 与外观设置。Key 可单独清除；已发出的请求可能继续完成。卸载扩展会移除本机扩展数据，不提供云同步。

Chrome 内部页面、扩展商店、PDF 等无法读取。若在 Chrome 中主动限制了扩展的网站访问，自动读取会受影响；侧栏会解释原因。插件不会绕过浏览器权限，也不会后台遍历标签页。

底部“AI可能会出错，请注意甄别”提醒你核对回答。完整数据流和本机保护边界见设置中的隐私说明。


## 阅读与字号（0.2.1）

在设置的“阅读与外观”中选择12px、13px（默认）、14px或16px。问题、回答、输入、代码和表格立即采用所选字号；偏好保存在本机，其他已打开的侧栏同步生效，重新打开后恢复。调整字号时正在浏览的历史消息不会被强制拉到底部。

向上浏览消息时，流式回答暂停自动跟随。距离底部超过100px时会出现向下箭头，点击“到底部”即可查看最新内容并恢复自动跟随。按钮只滚动插件消息区，不移动原网页。系统减少动态效果时直接定位。

图标悬停稍候或键盘聚焦时显示简短提示，移开、点击或按Esc关闭。原生侧栏最小宽度由Chrome决定，当前版本通过缩小内部留白提高窄屏利用率。


## 围绕文章理解内容（0.2.2）

新版默认引导模型结合选文解释它在文章中的作用和必要的上下游关系，并遵从当次简短或深入要求。文章说明不足时允许补充常识，区分文章原意与补充/推测；不能从未展示的实现断言项目缺少该实现。

发送前会在本次正文中尝试定位网页选文，可靠匹配时附上章节和邻近文字；多处出现或未找到时明确告知模型定位状态，不猜测位置。定位不会改变引用原文或增加模型调用。旧问题的失败重试及重新生成继续使用当时冻结的资料与提示；要使用新版阅读提示，请发送新问题。

思考和模型菜单保留原生选择方式，键盘聚焦时显示完整圆角内描边；下拉控件聚焦不再高亮整个输入容器。
